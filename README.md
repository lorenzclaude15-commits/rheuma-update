- `folgen/<Jahr>-Q<n>/` – Archiv aller Folgen mit Quellenlisten.
- Shownotes und Archiv zum Nachlesen: https://claude.ai/artifact/9fkwt56TYvaEinKsNQmeu4

Ersetzt nicht Fachinformation oder Leitlinie im Original. Keine Patientendaten.
